Лучше использовать версию 5.0.1-13, с ней лаба точно работает.
Скачать можно здесь https://disk.yandex.ru/d/mm0cFB3cfr3MWw

1. Поставить гипервизор (VMware Player)
2. Скачать и распаковать архив по ссылке выше
3. Двойной клик по шаблону ВМ EVE-COM-5.ovf
4. VMware Player должен предложить создать новую ВМ, выбрать папку, куда будет скопирован образ этой ВМ
5. Запустить ВМ
6. Логин root пароль eve
7. Установить пароль для root, выбрать имя ВМ и способ получения IP адреса (можно оставить все по умолчанию)
8. После загрузки будет указан URL (http://IP_адрес), по которому доступен интерфейс ВМ (адрес должен выдать ваш домашний роутер)
9. Использовать этот адрес для загрузки образов и доступа по SSH на ВМ
10. Скачать и распаковать IoL.zip из ЛК
11. Залить образы (bin файлы) по SFTP, используя WinSCP, в /opt/unetlab/addons/iol/bin вашей новой ВМ
12. Зайти по SSH на ВМ (можно использовать, например, PuTTY)
13. Скопировать и вставить в терминал всё, что ниже (между ##### )

#################
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions
cd /opt/unetlab/addons/iol/bin/
cat > script.py <<EOF
#! /usr/bin/python3
print("*********************************************************************")
print("Cisco IOU License Generator - Kal 2011, python port of 2006 C version")
import os
import socket
import hashlib
import struct
# get the host id and host name to calculate the hostkey
hostid=os.popen("hostid").read().strip()
hostname = socket.gethostname()
ioukey=int(hostid,16)
for x in hostname:
 ioukey = ioukey + ord(x)
print("hostid=" + hostid +", hostname="+ hostname + ", ioukey=" + hex(ioukey)[2:])
# create the license using md5sum
iouPad1 = b'\x4B\x58\x21\x81\x56\x7B\x0D\xF3\x21\x43\x9B\x7E\xAC\x1D\xE6\x8A'
iouPad2 = b'\x80' + 39*b'\0'
md5input=iouPad1 + iouPad2 + struct.pack('!i', ioukey) + iouPad1
iouLicense=hashlib.md5(md5input).hexdigest()[:16]
lic_files = ["iourc.txt", "iourc", "/root/.iourc"]
for lic_file in lic_files:
   with open(lic_file, "wt") as out_file:
      out_file.write("[license]\n" + hostname + " = " + iouLicense + ";\n")
print("You can disable the phone home feature with something like:")
print(" echo '127.0.0.127 xml.cisco.com' >> /etc/hosts\n")

EOF
python3 script.py 
cd /opt/unetlab/addons/iol/bin/
touch NETMAP
D_LIBRARY_PATH=/opt/unetlab/addons/iol/lib /opt/unetlab/addons/iol/bin/L2-ADVENTERPRISEK9-M-15.2-20150703.bin 1
##########

14. Если образ запустился без ошибок, все выполнено правильно. Можно его остановить - CTRL+C
15. Открыть интерфейс EVE-NG http://IP_адрес, логин admin, пароль eve (или от вашего пользователя root, если поставили другой пароль)
16. Скачать архив с лабой из ЛК (не распаковывать его)
17. В интерфейсе EVE-NG импортировать zip архив


Troubleshooting:
Может быть полезно смотреть логи
